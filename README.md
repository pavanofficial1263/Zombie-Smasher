# Zombie Smasher

## 2D Game Development Project

Zombie Smasher is a 2D game development learning project created using Unity and C#.

## Project Overview

This project was developed as part of my learning journey.

The project focuses on creating a simple zombie-themed gameplay experience, including player interaction, gameplay mechanics, visual elements, and game flow.

## My Contribution

- Followed and implemented the concepts learnt online
- Developed the game using Unity
- Implemented gameplay mechanics using C#
- Designed and arranged gameplay elements
- Practiced player interaction and game flow
- Tested and refined gameplay functionality
